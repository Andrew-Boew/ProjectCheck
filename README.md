# ProjectCheck

Локальная консольная утилита для проверки проекта перед публикацией. Она проверяет наличие README, `.gitignore` и Python-тестов, а также сообщает о файлах больше 10 МиБ, временных файлах (`.tmp`, `.bak`, `.swp`, `.swo`, `*~`, `.DS_Store`) и потенциально конфиденциальных файлах (`.env`, приватные ключи). Проверяемые файлы не изменяются.

```bash
python3 projectcheck.py /путь/к/проекту
```

Папки `.git`, `.venv`, `venv`, `node_modules` и `__pycache__` пропускаются. Сейчас замечания носят информационный характер: команда завершает работу с кодом `0`, если папка существует.

Предупреждение `SENSITIVE` основано только на имени файла: ProjectCheck не читает его содержимое и пока не учитывает, добавлен ли файл в Git. Шаблоны `.env.example`, `.env.sample` и `.env.template` не считаются конфиденциальными.
