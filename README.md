# ProjectCheck

Локальная консольная утилита для проверки проекта перед публикацией. На первом этапе она проверяет наличие README, `.gitignore` и Python-тестов. Проверяемые файлы не изменяются.

```bash
python3 projectcheck.py /путь/к/проекту
```

Сейчас замечания носят информационный характер: команда завершает работу с кодом `0`, если папка существует. Следующие проверки и формат отчёта добавим отдельными этапами.
