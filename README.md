# ProjectCheck

Локальная консольная утилита для проверки проекта перед публикацией. Она проверяет наличие README, `.gitignore` и Python-тестов, а также сообщает о файлах больше 10 МиБ и временных файлах (`.tmp`, `.bak`, `.swp`, `.swo`, `*~`, `.DS_Store`). Проверяемые файлы не изменяются.

```bash
python3 projectcheck.py /путь/к/проекту
```

Папки `.git`, `.venv`, `venv`, `node_modules` и `__pycache__` пропускаются. Сейчас замечания носят информационный характер: команда завершает работу с кодом `0`, если папка существует.
